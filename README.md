## Overlay Annotations

- **Red arrow boxes** — highlight buttons, CTAs, and key UI elements
- **Blue label chips** — name each feature being discussed
- **Amber glow markers** — draw the eye to active elements
- **Dimmed background** — isolates the focused element

## Usage

Open `stripe-v3-narrated.mp4` in any video player or browser.

### Generate your own

```bash
# with OpenAI TTS (human-like narration)
vixie generate https://example.com --tts openai --voice presales

# with free edge-tts
vixie generate https://example.com --tts edge --voice en-US-AvaNeural

# run the analyzer on your output
npx tsx src/cli.ts analyze output.mp4
```
